# Política de Privacidade — VALLIER.FLUX

## 1. Dados Coletados
Ao utilizar o formulário de contato do site **VALLIER.FLUX**, são coletados exclusivamente os dados informados voluntariamente por você:
- **Nome**
- **Endereço de e-mail**
- **Mensagem**

Nenhum cookie de rastreamento publicitário ou telemetria invasiva é utilizado.

## 2. Finalidade e Operador de Envio
Os dados submetidos são encaminhados via HTTPS para o serviço **Formspree** (`https://formspree.io`), utilizado estritamente como provedor de entrega de mensagens para responder à sua solicitação técnica ou comercial.

## 3. Retenção e Direitos do Titular
As informações são mantidas apenas pelo tempo necessário para o atendimento do contato. Você pode solicitar a exclusão ou revisão dos dados enviados entrando em contato diretamente pelo e-mail publicado na seção de contato.
